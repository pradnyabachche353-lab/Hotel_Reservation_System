# Hotel Reservation System

A console-based Hotel Reservation System built using **Java, JDBC, and MySQL**.  
The application allows users to create, view, update, retrieve, and delete hotel reservations through a simple command-line interface.

## Features

- Reserve a hotel room
- View all reservations
- Retrieve room number using reservation ID and guest name
- Update reservation details
- Delete a reservation
- Validate reservation existence before updating
- MySQL database integration using JDBC
- Parameterized SQL queries using `PreparedStatement`

## Technologies Used

- **Java**
- **JDBC (Java Database Connectivity)**
- **MySQL**
- **IntelliJ IDEA**
